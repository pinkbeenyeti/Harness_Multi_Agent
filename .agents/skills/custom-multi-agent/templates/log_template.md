# Work Log (Append-Only)

*이력은 지우지 않고 시간 순으로 쌓기만 합니다. 수정과 삭제는 금지입니다.*

*포맷 (고정): `YYYY-MM-DD HH:MM [TAG] 내용`*
*시각(HH:MM)을 생략하지 마십시오. 생략하면 `collect_metrics.py`가 소요시간을 계측하지 못합니다.*
*표준 태그: DECISION, APPROVAL, WORKER_CALL, VERIFICATION, ERROR, COMPLETE, METRICS*
*부속 설명은 다음 줄에 두 칸 들여쓰기로 답니다.*

[YYYY-MM-DD HH:MM] [DECISION] 태스크 폴더 및 작업 파일이 생성되고 초기화되었습니다.
