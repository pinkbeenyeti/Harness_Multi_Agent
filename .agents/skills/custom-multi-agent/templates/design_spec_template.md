## 4. 의존 그룹 및 병렬 실행 계획 (Dependency Groups)

수정 대상이 3개 파일 이상일 때만 작성한다. 같은 그룹 = 한 워커가 순차 처리, 다른 그룹 = 병렬 기동.

| 그룹 | 파일 | 산출물 | 같은 그룹인 이유 |
|---|---|---|---|
| `core` | [경로 L범위] | `result_core.md` / `critic_report_core.md` | [예: A가 신설한 심볼을 B가 소비] |
| `infra` | [경로 L범위] | `result_infra.md` / `critic_report_infra.md` | [독립 — 다른 그룹과 심볼 공유 없음] |

* **그룹 분리 근거**: [그룹 간에 심볼 의존·시그니처 동반 변경·부분 반영 시 컴파일 실패가 없음을 명시]
* 판단이 서지 않는 파일은 **같은 그룹으로 묶는다.** 그룹이 1개면 병렬화하지 않는다.
* 병합은 전 그룹 비평 통과 후 **한 번에** 수행한다(부분 병합 금지).
